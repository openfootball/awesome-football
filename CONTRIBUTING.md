# Contributing to Awesome Football

This document describes how the openfootball/awesome-football project accepts contributions.

## How the Project Accepts Contributions

Per the README: *"Contributions welcome. Anything missing? Send in a pull request. Thanks."*

### Contribution Methods

1. **Pull Requests (PRs)** — The primary and preferred method for all contributions
2. **Fork + Branch** — Fork the repo, create a feature branch, make changes, and submit a PR
3. **Issues** — Open an issue to discuss ideas before implementing them

### What's Welcome

- **Datasets** — Open football datasets (match schedules, player stats, stadium data, etc.)
- **Apps & Tools** — Open source tools for match scores, predictions, office pools, etc.
- **Technology** — Libraries, scrapers, APIs, and data pipelines
- **Cultural & Community Content** — Match day traditions, fan experiences, community discussions, and cultural documentation (see [NON-LEAGUE-COMMUNITY-CULTURE.md](NON-LEAGUE-COMMUNITY-CULTURE.md))
- **Documentation** — Guides, articles, and research summaries
- **Fixes & Improvements** — Bug fixes, broken links, and data corrections

### Contribution Guidelines

1. **Fork the repo** — Create your own fork of openfootball/awesome-football
2. **Create a branch** — Use a descriptive branch name (e.g., `add-non-league-community-culture`)
3. **Make focused changes** — Keep PRs small and focused on one topic
4. **Avoid merge conflicts** — Keep your branch updated with the latest `master`
5. **Commit with a clear message** — Describe what you added and why
6. **Open a PR** — Submit against the `openfootball:master` branch
7. **Be patient** — Maintainers review PRs in their spare time

### Content Guidelines

- **Public domain** — All content in this project is dedicated to the public domain. Use it as you please with no restrictions.
- **Cite sources** — Where possible, include references to original sources
- **Keep it current** — Data and prices change; update content regularly
- **Be inclusive** — Respect diverse communities and perspectives

### Non-League & Cultural Content

For contributions about non-league match day culture and fan community discussions:

- Add new files with descriptive names (e.g., `NON-LEAGUE-COMMUNITY-CULTURE.md`)
- Reference existing content in the README
- Include a source bibliography
- Keep content dedicated to the public domain
- Update the README's Football Culture section if you add significant new sections

### License

The awesome-football project is dedicated to the **public domain**. All content is freely usable with no restrictions whatsoever.
