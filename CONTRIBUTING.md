# Contributing to awesome-football

## How This Project Accepts Contributions

Per the project README: **"Contributions welcome. Anything missing? Send in a pull request. Thanks."**

### Primary Contribution Method

Pull requests to the `master` branch of the [openfootball/awesome-football](https://github.com/openfootball/awesome-football) repository.

### What Can You Contribute?

- **Datasets** — Open football data in CSV, JSON, or other formats
- **Apps & Tools** — Open source projects for scores, predictions, and community
- **Technology** — Libraries, APIs, and integrations
- **Cultural Content** — Documentation of match day traditions, fan experiences, and community practices (this area is growing!)
- **Documentation** — Guides, reading lists, and research summaries
- **Fixes** — Bug fixes, broken links, and updates

### Content Guidelines

1. **Cite your sources** — Link back to the original community discussions, publications, and data providers
2. **Keep it current** — Verify that links and facts are up to date before submitting
3. **Be inclusive** — Represent the full diversity of the football community
4. **Public domain** — Content contributed to this project is dedicated to the public domain
5. **Match the style** — Follow the existing README format with clear headings, bullet points, and tables

### PR Process

1. Fork the repo
2. Create a new feature branch
3. Make your changes
4. Push to your fork
5. Open a pull request against `master`

### Questions?

- See the [openfootball/help](https://github.com/openfootball/help) repository
- Join the [Google Group / opensport](http://groups.google.com/group/opensport) for discussion
