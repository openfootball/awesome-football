# Contributing to awesome-football

## How The Project Accepts Contributions

As stated in the README: **"Contributions welcome. Anything missing? Send in a pull request. Thanks."**

### Primary Contribution Method

- **Pull Requests (PRs)** are the main way to contribute
- Create a feature branch from `master`
- Submit a PR targeting the `master` branch
- All content is dedicated to the **public domain** — no license restrictions

### Contribution Types Welcome

1. **Data/Technology** — datasets, APIs, tools, schemas
2. **Documentation** — guides, articles, cultural content
3. **Research** — curated summaries of player databases, league resources, etc.
4. **Fan Culture & Community** — match day experiences, traditions, grassroots voices

### Guidelines for Contributions

- **Keep it public domain**: all content should be sourced from open web sources and dedicated to the public domain
- **Add source URLs**: always include references and links to original sources
- **Logical placement**: add content to the most appropriate section in the README
- **Create supporting files**: for substantial content, commit a markdown file alongside the README update
- **One topic per PR**: keep PRs focused on a single clean addition
- **Avoid merge conflicts**: rebase before submitting; don't duplicate existing content

### Contribution Pipeline

```
Fork → Branch → Commit/File → PR → Review → Merge
```

- Fork `openfootball/awesome-football` to your account
- Create a descriptive branch name (e.g., `add-non-league-culture-content`)
- Add or update files
- Push and open a PR with a clear description of additions
- Lookup openfootball/help repo for additional questions

For discussions and questions, see:
- [openfootball/help](https://github.com/openfootball/help)
- [Google Group](http://groups.google.com/group/opensport)
